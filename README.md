# BlockVerse Prototype

A lightweight voxel sandbox prototype built with Three.js and Vite.

## Features
- First-person controls with pointer lock
- Procedural terrain generation with water, trees, and stones
- Block mining and placement
- Simple quickbar inventory
- Day/night lighting cycle
- Local save/load using browser storage

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the URL shown in the terminal.

## Build for production

```bash
npm run build
```
